Good to know

Frequently asked questions.

How do I install the app?

Press Download for Android to get the APK directly. Open it and follow Android’s installation prompts. No signup or ZIP extraction is required.

Will it work on my phone?

The project targets Android 9 and later. Camera features depend on hardware and actual compatibility requires testing. iOS is not supported.

Is it really free?

No signup, ads or payments are required for this application.

Is version 5.0 a finished release?

No. It is a development preview; device testing is pending. The 5.0 preview uses a different signing certificate from C.CAM Ultra 4.1. Android requires a fresh installation if you have that build. Before removing 4.1, save any captures you want to keep.
