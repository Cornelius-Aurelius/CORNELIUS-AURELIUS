# AI Music media folder

This folder is where the six full-length AI Music recordings and cover images belong.

Upload the files from **Cornelius_Aurelius_AI_Music_Listening_Page.zip** → **music-assets/** into this GitHub folder. Do not upload the ZIP itself; upload the files inside that folder.

The audio files are:
- daylight-can-wait.m4a
- second-to-montana.m4a
- brave-enough-to-love-again.m4a
- my-heart-left-without-me.m4a
- while-were-here.m4a
- dont-let-the-wrong-love-break-you-twice.m4a

Also upload the matching six files ending in .webp from the package.

Once committed to the default branch and GitHub Pages finishes deploying, the music page automatically enables the correct audio player and cover image for each song. Do not rename the files.

The AI Music page lives at https://corneliusaurelius.com/ai-music.html.
