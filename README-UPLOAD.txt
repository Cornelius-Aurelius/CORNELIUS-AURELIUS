UPLOAD METHOD
1. Back up the current repository before replacing files.
2. Upload this package into the ROOT of Cornelius-Aurelius/CORNELIUS-AURELIUS.
3. Do NOT delete the existing media assets, favicons, Google verification file or other files unless separately reviewed.
4. Allow GitHub Pages to redeploy.
5. Check https://corneliusaurelius.com/ and the main subpages.
6. Submit https://corneliusaurelius.com/sitemap.xml in Google Search Console.
7. After exact generic media files are identified, add them to the prepared Piano / Drums / Paintings / Football landing pages and create VideoObject + video sitemap entries for actual video pages.
